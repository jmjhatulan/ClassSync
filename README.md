# ClassSync
ClassSync is a centralized hub of digital tools and utilities designed to support both teaching and learning. It provides teachers and students with convenient, accessible, and practical solutions for academic tasks, classroom activities, and productivity.

Current Apps Available
- [PDF Presenter](https://jmjhatulan.github.io/ClassSync/presenter/)
- [Grade Target Calculator](https://jmjhatulan.github.io/ClassSync/calculator/)
- [Randomizer](https://jmjhatulan.github.io/ClassSync/randomizer/)
